# DeepThought Business Analytics Assignment

This repository contains the completed assignment for the DeepThought Business Analytics Target Company Research task.

## Contents

- `deepthought_target_company_research.csv` → Final company research dataset
- `deepthought_target_company_research.xlsx` → Excel version of dataset
- `methodology.md` → Research methodology and scoring logic
- `proposal_1000_companies.md` → Scaling proposal for researching 1000 companies
- `research_script.py` → Python script used for research workflow

## Assignment Objective

Research and score companies using Federer-style evaluation criteria:
- Fan Following
- Funding
- Founder Background
- Product Quality
- Revenue Potential
- Market Presence

- Dataset includes 25 researched companies
- Scores are normalized and ranked
- Proposal includes scalable automation strategy
